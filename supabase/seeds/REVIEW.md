## What you can do

1. **Reading passages.** Many reading questions say "according to the text", but
   the texts themselves are not in the sheet, so students could only guess. Type
   each passage into the sheet (or send the scans) and those questions can go live.
2. **Questions with more than one right answer** ("choose the true statements"
   with no A-E list). The app marks one choice per question. Write A-E options
   that list statement numbers ("A) 1, 4"), the way the paper does elsewhere.
3. **Check the Russian.** Every Russian Language question was written in English
   in the sheet, so it was put into Russian by machine. Anything in «quotes» was
   kept exactly as you typed it; the rest needs your eye. Rows marked *yes* in
   the last column.
4. **Pictures.** Questions with a diagram are not loaded yet (list at the end).
   Add each picture through the admin page.

## How topics are named in the app

Your sheet's topics are grouped into the topics students pick in the test
builder. Your exact topic is still saved with each question.

- **English**: Reading → `reading`, Grammar → `grammar`, Vocabulary → `vocabulary`, Writing → `writing`
- **Russian Language**: Phonetics → `phonetics`, Morphology → `grammar`, Syntax → `grammar`, Orthography → `spelling`, Vocabulary → `vocabulary`, Phraseology → `vocabulary`, Reading → `reading`, Text Analysis → `reading`, Reading / Writing → `writing`
- **Maths**: Arithmetic → `arithmetic`, Algebra → `algebra`, Geometry → `geometry`, Coordinate Geometry → `coordinate-geometry`, Number Theory → `number-theory`, Sets & Logic → `sets-logic`, Probability → `probability`, Statistics → `probability`
